# Blog redesign v3 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the Only Learn blog look like `design/referensi/redesign-v3.jpg`, and make search, sorting, topic filter, Save (localStorage plus a `/tersimpan` page) and the Resend email signup work. Add `thumbnail` support for Morena.

**Architecture:**
- Content pages stay static (SSG).
- The home page embeds a small serialisable index of articles. Client components search, filter and sort it with pure functions from `src/lib/jelajah.ts`.
- Save uses pure helpers in `src/lib/simpan.ts` plus a client hook.
- One Node Route Handler, `/api/langganan`, calls Resend's REST API through a pure, testable `src/lib/langganan.ts`.
- Illustrations are generated once with Cloudflare Workers AI and committed as JPEGs.

**Tech Stack:** Next.js 16 App Router, React 19, Tailwind CSS 4 tokens from DESIGN.md (`npm run tokens`), zod 4, tsx `node:test`, Cloudflare Workers AI REST, Resend REST. No new npm dependencies.

**Spec:** `docs/superpowers/specs/2026-10-31-redesign-v3-design.md`. It holds the palette, decisions and thumbnail contract. Read it before every task.

### Task 4: Sidebar — email signup (Resend) and Kategori Populer

**Files:**

**Interfaces:**
- **`langganan.ts`:**

  ```ts
  export type Hasil = { status: number; pesan: string };
  export const validasi: (body: unknown) => { ok: true; email: string } | { ok: false; hasil: Hasil };
  export const daftarkan: (email: string, env: { RESEND_API_KEY?: string; RESEND_SEGMENT_ID?: string }, f?: typeof fetch) => Promise<Hasil>;
  ```

  `validasi` uses zod strictObject `{ email: z.email().max(254), situs: z.string().max(0).optional() }`, where `situs` is the honeypot. It returns:
  - a filled honeypot → `{ ok:false, hasil:{status:200, pesan:"Terima kasih! Kamu sudah terdaftar."} }`, a silent fake success;
  - an invalid email → `{status:400, pesan:"Email tidak valid."}`;
  - a non-object body → `{status:400, pesan:"Permintaan tidak valid."}`.

  `daftarkan` returns:
  - no key → `{status:503, pesan:"Langganan belum aktif. Coba lagi nanti."}` without calling `f`;
  - otherwise it does a POST to `https://api.resend.com/contacts` with `Authorization: Bearer <key>`, `Content-Type: application/json`, and a body of `{ email, unsubscribed: false, ...(segment ? { segments: [{ id: segment }] } : {}) }`, with a 10 s timeout (`AbortSignal.timeout(10_000)`);
  - 2xx → `{status:200, pesan:"Terima kasih! Kamu sudah terdaftar."}`;
  - a 409 or 422 whose message mentions an existing contact → the same success;
  - any other failure or a network error → `{status:502, pesan:"Gagal mendaftar. Coba lagi sebentar lagi."}`. Never include the key or Resend's raw body in `pesan`.
- **`route.ts`:**
  - `export const runtime = "nodejs"`, `export const dynamic = "force-dynamic"`.
  - `POST` parses JSON in try/catch (on failure → 400 "Permintaan tidak valid."), then calls `validasi` and `daftarkan(email, process.env)`, and returns `Response.json({ pesan }, { status })`.
  - No GET.
- **`Langganan` (client):**
  - A navy card (`bg-navy`, `rounded-3xl`, white text) using `/ilustrasi/langganan.jpg` as a bottom/right background layer under a navy gradient overlay, so the text keeps ≥ 4.5:1 contrast.
  - Title "Ikuti perjalanan belajar kita!" and text "Dapatkan artikel terbaru dan insight menarik lainnya."
  - The form: an email input (label "Email kamu" visually hidden, placeholder "Email kamu…", `type=email`, required), the hidden honeypot field `situs` (`tabIndex=-1`, `autoComplete="off"`, offscreen), and a round submit button with an arrow (`aria-label="Daftar"`).
  - States: sending (button disabled), success (the message replaces the form), and error (the message appears under the input, `role="status"`).
- **`KategoriPopuler({ hitung: Record<TopicSlug, number> })`:**
  - A white `rounded-3xl` card headed "Kategori Populer" with a small bar-chart icon.
  - Rows: an emoji circle, the topic name, and an "N artikel" pill, each row linking to `/topik/<slug>`.
  - A last row "💡 Cara aku riset" links to `/cara-aku-riset`, without a count.
